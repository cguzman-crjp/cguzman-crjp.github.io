WORD QUEST JAPAN — STATIC WEBSITE

How to open:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Keep the folder structure unchanged.

What works offline:
- All pages, navigation, quizzes, flashcards, matching activities, progress tracking, theme toggle, and printable worksheet.

What needs internet access:
- YouTube videos, Oxford Learner's Dictionaries, YouGlish, BBC Learning English, and Vocabulary.com.

Browser notes:
- Progress is stored locally in the browser using localStorage.
- Audio word buttons use the browser's speech-synthesis feature. Voices differ by device.
- Use a modern browser for the best experience.

Main files:
- index.html: start page
- assets/css/style.css: visual design
- assets/js/main.js: navigation, progress, audio, saved notes
- assets/js/activities.js: quizzes, flashcards, matching, planner

This prototype can later be published with GitHub Pages, Netlify, Cloudflare Pages, or adapted into WordPress/Wix content blocks.
